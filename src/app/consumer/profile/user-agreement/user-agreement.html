前言

欢迎使用再生视界服务！

《再生视界用户服务协议》（以下简称"本协议"）是您与再生视界科技有限公司（以下简称"我们"或"再生视界"）之间关于您使用再生视界服务所订立的协议。

请您仔细阅读本协议的全部条款，特别是免除或者限制责任的条款、法律适用和争议解决条款。如果您不同意本协议的任意内容，或者无法准确理解我们对条款的解释，请不要进行后续操作。

第一条 协议的范围

1.1 本协议是您与再生视界之间关于您使用再生视界服务所订立的协议。

1.2 "再生视界服务"是指再生视界向用户提供的包括但不限于回收预约、积分兑换、环保知识分享等服务。

1.3 本协议适用于您使用再生视界提供的所有服务，包括但不限于移动应用程序、网站、小程序等。

第二条 服务内容

2.1 再生视界为用户提供以下服务：

  • 回收物品预约上门服务
  • 回收物品价格查询和估算
  • 积分奖励和兑换服务
  • 环保知识和资讯分享
  • 用户社区和互动功能
  • 其他相关增值服务

2.2 再生视界有权根据业务发展需要，增加、修改或终止部分服务功能。

第三条 用户注册

3.1 用户需要注册账户才能使用再生视界的完整服务。

3.2 用户应提供真实、准确、完整的个人信息，并及时更新。

3.3 用户应妥善保管账户信息，不得将账户转让、出借或以其他方式提供给第三方使用。

3.4 用户对其账户下的所有活动承担责任。

第四条 用户权利和义务

4.1 用户权利：

  • 享受再生视界提供的各项服务
  • 获得积分奖励和相应权益
  • 对服务质量进行监督和反馈
  • 要求保护个人隐私和信息安全

4.2 用户义务：

  • 遵守国家法律法规和本协议
  • 提供真实有效的回收物品信息
  • 配合回收员完成回收服务
  • 不得利用服务从事违法违规活动
  • 尊重其他用户和工作人员

第五条 服务规范

5.1 回收服务规范：

  • 用户应准确描述回收物品的类型、数量和状态
  • 预约时间确定后，用户应按时等候回收员上门
  • 回收物品应符合回收标准，不得包含危险品
  • 回收价格以现场评估为准

5.2 积分规则：

  • 积分获取规则以平台公布为准
  • 积分不得转让、买卖或以其他方式变现
  • 积分有效期为获得之日起一年

第六条 隐私保护

6.1 再生视界重视用户隐私保护，具体内容请参阅《隐私政策》。

6.2 再生视界承诺不会向第三方泄露用户个人信息，法律法规另有规定的除外。

6.3 为提供更好的服务，再生视界可能会收集和使用用户的相关信息，但会严格按照隐私政策执行。

第七条 知识产权

7.1 再生视界服务中的所有内容，包括但不限于文字、图片、音频、视频、软件、程序、版面设计等均受知识产权法保护。

7.2 未经再生视界书面许可，用户不得复制、传播、展示、镜像、上载、下载使用上述内容。

7.3 用户在使用服务过程中产生的内容，授权再生视界在服务范围内使用。

第八条 免责声明

8.1 因以下情况造成的服务中断或其他缺陷，再生视界不承担责任：

  • 系统停机维护期间
  • 电信设备出现故障不能进行数据传输
  • 因台风、地震、海啸、洪水、停电、战争、恐怖袭击等不可抗力因素
  • 因病毒、木马、恶意程序攻击、网络拥堵、系统不稳定等

8.2 用户理解并同意，再生视界不对因以下事由产生的损失承担责任：

  • 用户自身原因导致的任何损失
  • 第三方行为导致的损失
  • 不可抗力导致的损失

第九条 协议修改

9.1 再生视界有权根据需要修改本协议条款。

9.2 协议修改后，再生视界会在应用内或官网发布公告。

9.3 如果用户不同意修改后的协议，可以停止使用服务；继续使用服务则视为接受修改后的协议。

第十条 争议解决

10.1 本协议的签订、履行、解释及争议解决均适用中华人民共和国法律。

10.2 如就本协议内容或其执行发生任何争议，双方应尽量友好协商解决。

10.3 协商不成时，任何一方均可向再生视界所在地人民法院提起诉讼。

第十一条 其他条款

11.1 本协议构成双方对本协议之约定事项及其他有关事宜的完整协议。

11.2 本协议中的标题仅为方便而设，在解释本协议时应被忽略。

11.3 本协议部分条款被认定为违法或无效不影响其余条款的效力。
